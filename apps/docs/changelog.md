# 更新日志

本页记录多元记值得关注的变化。

格式参考 [Keep a Changelog](https://keepachangelog.com/en/2.0.0/)，项目按日期发布，最新内容在前。

## 尚未发布

### 新增

- 上线多元记使用指南，介绍记录、筛选、分享与存储等功能。
- 增加“写在前面”，说明多元记整理离散数据的初衷。

## 2026-08-02

### 新增

- 支持把筛选结果创建为固定分享或动态分享。
- 分享链接无需登录即可查看，并支持继续加载更多记录。

### 变更

- 优化图片查看体验。
- 登录后自动返回原页面。

## 2026-07-31

### 新增

- “我的”支持按可见范围、时间、正文、人员和标签筛选记录。
- 支持从筛选结果中排除个别记录。

### 变更

- 记录详情支持直接切换公开与隐私状态。
