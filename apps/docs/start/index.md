# 开始使用多元记

记录不是把生活变成一份清单，而是给那些不愿忘记的时刻留一个位置。

## 注册或登录

进入“我的”。尚未登录时会先前往登录页；没有账号，可以直接注册并登录。

## 写下第一条记录

在“我的”顶部输入内容并发送，一条记录就完成了。

新记录默认仅自己可见。发送前，还可以设置事情真正发生的时间、加入图片、视频、音频或文件，或者把它公开。保存后，记录会按照记录时间进入“我的”时间线。

## 四个主要入口

| 入口 | 用途 |
| --- | --- |
| 首页 | 浏览所有人公开的记录 |
| 我的 | 创建、筛选和管理自己的记录 |
| 地图 | 查看当前位置和周边地图 |
| 个人 | 查看账户、切换外观和了解存储用量 |
