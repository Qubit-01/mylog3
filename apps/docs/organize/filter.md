# 筛选记录

记录多了以后，寻找也是一种重新理解。筛选帮你从许多日子中，找到此刻真正想看的那一部分。

在“我的”中选择“筛选”，结果会随着条件自动更新。

## 筛选条件

| 条件 | 作用 |
| --- | --- |
| 范围 | 只看隐私记录、公开记录，或者全部 |
| 时间 | 限定记录发生的日期 |
| 正文 | 查找包含指定关键词的记录 |
| 人员 | 查找记录中关联的人员 |
| 标签 | 查找带有指定标签的记录 |
| 排除 | 移除指定编号的记录 |

::: info 实现原理
筛选条件会交给服务端执行，匹配的是账户下的全部记录，而不是浏览器已经加载的这一页。页面再按记录时间分批取回结果。
:::

## “和”与“或”

- **和**要求所有条件同时成立，例如同时包含“旅行”和“成都”。
- **或**只要求其中一个成立，例如包含“旅行”或“散步”。

“条件组”控制正文、人员和标签这几组条件之间的关系。

## 排除个别记录

筛选状态下，可以排除不想出现在结果中的记录。排除只改变当前结果，不会删除原记录。

## 分享筛选结果

筛选完成后，可以把当前结果创建为固定分享或动态分享。两种方式对未来记录的处理不同，详见[分享记录](/organize/share)。
