# 分享记录

分享不等于公开全部生活。它更像从自己的时间里挑出几页，交给某个人阅读。

在“我的”中设置筛选条件并选择分享方式，多元记会生成一条无需登录即可打开的链接。分享包含所有符合条件的记录，不限于页面已经加载的部分。

## 固定分享与动态分享

| 方式 | 适合什么情况 | 之后会怎样 |
| --- | --- | --- |
| 固定分享 | 一次旅行、一个阶段或已经确定的一组记录 | 新记录不会自动加入 |
| 动态分享 | 持续分享某个主题或时间范围 | 未来符合条件的记录会自动出现 |

固定分享固定的是记录名单，不是内容副本；动态分享则会重新执行原来的筛选条件。记录修改或删除后，分享结果也会相应变化。

::: info 实现原理
创建固定分享时，服务端保存当时匹配到的全部记录编号；创建动态分享时，服务端保存筛选条件。分享链接携带加密凭证，用它找到对应的分享规则。
:::

## 分享与隐私

- **隐私记录**不会出现在公开首页。
- **分享记录**会对持有分享链接的人开放，即使它原本是隐私记录。

::: danger
分享链接就是查看凭证。任何拿到链接的人都能打开其中的记录和附件，而且链接不会因为关闭页面而自动失效。
:::

链接应当像一把钥匙，只交给你愿意让其进入这段生活的人。
