# 创建与管理记录

生活发生的时间和我们写下它的时间，常常不是同一刻。多元记把两者分开：你可以现在写，也可以让记录回到它真正发生的那一天。

## 创建记录

进入“我的”，在顶部写下正文并发送。还可以设置：

- **记录时间**：这件事真正发生的时间；
- **多元内容**：与文字一起保存的图片、视频、音频或文件；
- **可见范围**：仅自己可见，或者公开。

没有单独设置时间时，多元记会使用发送时的时间。

## 记录时间

设置记录时间后，内容会按照这个时间进入“我的”时间线。今天补写去年的旅行，它仍会回到去年，而不会挤在今天的记录中。

::: info 实现原理
系统分别保存创建时间（`createdAt`）和记录时间（`logAt`）。“我的”时间线按照记录时间排列，因此补记不会改变事情原本的先后顺序。
:::

## 公开与隐私

每条新记录默认都是隐私记录，也可以在编辑器或详情页切换为公开。

| 状态 | 谁可以看见 |
| --- | --- |
| 隐私 | 通常只有你自己；加入分享后，持有分享链接的人也能看见 |
| 公开 | 你自己、公开首页的访问者，以及包含它的分享链接访问者 |

公开是一种选择，而不是记录的代价。可以先为自己写下，再决定是否让别人看见。

::: warning
隐私记录不会出现在公开首页，但仍然可以加入分享。创建分享前，请确认其中没有超出分享意愿的内容。
:::

## 编辑与删除

打开记录详情，可以修改内容和附件、切换公开状态或删除记录。删除后无法恢复。
