# 记录多元内容

文字保存我们的理解，影像和声音保存当时的光线与气息。它们不必互相替代，可以一起组成一条完整的记录。

## 图片与视频

在记录编辑器中，可以一次选择多张图片或视频。

## 照片的拍摄时间

多元记会尝试读取照片保存的拍摄时间。读取成功后，可以直接用它替换整条记录的时间。

这很适合整理旧照片：记录写在今天，却仍然属于照片拍下的那一天。没有可用的拍摄时间时，也可以手动设置。

::: info 实现原理
照片选入后，浏览器会在本地读取其中的 EXIF 信息，并生成用于展示的轻量预览；原图和预览随后分别保存，原图本身不会被压缩替换。
:::

## 音频与文件

音频可以在记录中直接播放，其他文件则以附件形式保存和下载。

## 多元内容的可见范围

附件跟随整条记录的可见范围。一条记录被公开或加入分享时，其中的图片、音频和文件也会随之开放。
