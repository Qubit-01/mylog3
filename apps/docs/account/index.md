# 账户、外观与存储

工具应当安静地适应使用它的人。账户、外观和存储集中在个人页，需要时查看，不需要时退到一旁。

## 账户与外观

个人页展示当前用户名、用户编号和加入时间，也可以在跟随系统、浅色和深色三种外观之间切换。

外观选择保存在当前浏览器中，不会改变其他设备。

## 存储用量

“存储信息”展示文件总量和已用空间，并区分原文件、预览文件、目录和文件类型。

::: info 实现原理
图片会保留原文件，同时生成更轻量的预览文件用于日常展示。这样既保留原始内容，也能减少浏览记录时需要传输的数据。
:::

## 退出登录

退出只结束当前浏览器中的登录状态，不会删除账户、记录或附件。
